Dari VM ke internet

Tugas infrastruktur web: dari mesin virtual sampai website bisa dibuka dari internet.

  1. Bangun website

    Web server berjalan di mesin virtual VirtualBox.

  2. Pasang panel

    Panel Barepod untuk mengelola server.

  3. Beli domain

    Nama domain dibeli lewat SumoPod.

  4. Sambungkan tunnel

    Cloudflare Tunnel mengarahkan domain ke VM.

  5. Online

    Website bisa dibuka dari internet.
